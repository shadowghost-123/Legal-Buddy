
# ⚖️ Legal Buddy

**Legal Buddy** is a smart legal guidance platform designed to help people understand their legal rights and possible remedies in simple language.

The platform allows users to describe their legal problem, identify relevant laws and sections, and receive step-by-step guidance. It also provides legal articles, complaint templates, emergency resources, and useful government/legal-service links.

> **Note:** Legal Buddy is an educational and guidance platform. It does not replace professional legal advice from a qualified lawyer.

---

## 🎯 Objective

The main objective of Legal Buddy is to make basic legal information more **accessible, understandable, and user-friendly** for people who may hesitate to approach the police or courts due to fear, lack of awareness, or unfamiliarity with legal procedures.

---

## ✨ Key Features

### 🔍 1. Legal Problem Guidance

Users can describe or select their problem and receive relevant information about possible legal remedies and next steps.

### ⚖️ 2. Law & Articles

Provides a searchable collection of important laws and legal sections with:

* Act name
* Section/article number
* Simple explanation
* Relevant category
* Applicable provisions
* Keywords

### 🤖 3. Legal Chatbot

An interactive chatbot helps users understand basic legal questions and navigate the available resources.

### 📝 4. Complaint Templates

Provides structured templates and formats that can help users prepare complaints or applications.

### 📚 5. Legal Resources

Includes useful:

* Government portals
* Legal-aid resources
* Helpline information
* Cybercrime reporting resources
* Consumer complaint resources

### 🔒 6. Privacy & Anonymous Access

The system is designed to allow users to seek general legal information without unnecessarily revealing personal information.

### 🌐 7. Simple & Accessible Interface

Legal information is presented in easy-to-understand language so that users without a legal background can navigate it easily.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd Legal-Buddy
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

### 3. Activate the Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```

Then open the local URL shown by the application in your browser.
